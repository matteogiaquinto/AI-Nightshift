# Tasks

Prefer GitHub issues for real tasks. Use this folder for quick capture, drafts, or task files that should later become issues.

## Folders

```text
inbox/                 New task files waiting for review
archive/done/          Completed task files
archive/skipped/       Skipped or rejected task files
archive/needs-human/   Tasks that require clarification
```

## Rules

- Do not let agents process files with `status: draft`.
- Mark files `status: ready` only when they are clear and safe.
- Prefer moving important tasks to GitHub issues so labels and comments are tracked.
- Keep one task per file.

## File naming

Use:

```text
YYYY-MM-DD-short-task-title.md
```

Example:

```text
2026-07-07-fix-mobile-navbar-overflow.md
```
