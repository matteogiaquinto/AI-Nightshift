# Contributing

AI Nightshift is a reusable workflow template. Contributions should make the template safer, clearer, or easier to adapt.

## Good contributions

- clearer documentation
- better issue templates
- safer default rules
- improved review checklists
- agent-agnostic integration notes
- label or workflow improvements

## Out of scope

- personal task queues
- private project details
- client-specific examples
- tool-specific lock-in
- broad automation that removes human review

## Privacy rule

Do not include personal tasks, customer names, internal screenshots, private URLs, credentials, or unreleased project details in issues, pull requests, examples, or docs.

## Pull requests

Every pull request should explain:

- what changed
- why it helps the template
- whether it affects the default safety rules
- whether existing users need to change labels or prompts
